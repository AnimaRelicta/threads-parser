# Сбор веток по списку ссылок (`postlist.py`)

Пополняет таблицу `posts` ветками, ссылки на которые вы положили в `data/threads_posts.txt`.
Работает как поиск по запросам из `threads_queries.txt`, только вместо выдачи открывается
каждая указанная ветка. Нужны аккаунты (`scripts/accounts.py`) и миграции БД.

## Файл `data/threads_posts.txt`

По одной ветке в строке; пустые строки и строки с `#` игнорируются:

```text
https://www.threads.com/@ник/post/КОД
@ник/post/КОД
https://www.threads.com/t/КОД
КОД
```

Для новой ветки нужна ссылка с ником (`/@ник/post/КОД`). Короткая ссылка `/t/КОД` и голый
`КОД` подходят только для веток, которые уже есть в БД: ник берётся оттуда. Повторы в файле
схлопываются по коду.

## Запуск

```bash
uv run scripts/postlist.py --dry-run          # сколько новых и к обновлению, без браузера
uv run scripts/postlist.py                    # собрать только новые ветки
uv run scripts/postlist.py --refresh          # ещё и обновить те, что уже в БД
uv run scripts/postlist.py --refresh --stale-days 3   # обновить только не менявшиеся 3+ дня
uv run scripts/postlist.py https://www.threads.com/@ник/post/КОД   # ссылки из командной строки
```

| Флаг | Смысл |
| --- | --- |
| `--file` | другой файл со ссылками (по умолчанию `POSTS_FILE`) |
| `--refresh` | открыть заново ветки, которые уже есть в БД (без флага они пропускаются) |
| `--stale-days N` | с `--refresh`: только ветки, не менявшиеся N дней и больше |
| `--workers`, `--accounts`, `--headless` | вкладки на аккаунт и аккаунты |
| `--delay` | пауза между ветками на вкладке, сек (по умолчанию `0.3`, реально `0.5x..1.5x`) |
| `--dry-run` | только разобрать файл и сверить с БД |

Настройки в `scripts/.env`: `POSTS_FILE`, `POSTS_WORKERS`, `POSTS_DELAY`.

## Что попадает в БД

- Новая ветка: строка в `posts` с `first_seen_via = 'search'` и `last_refreshed_at IS NULL`
  («не разобрана»): `run.py --fill-threads` и полный проход потом доберут комментарии и медиа.
  Автор привязывается к `profiles`, если такой профиль уже есть.
- Существующая ветка (только с `--refresh`): обновляются лайки, ответы, репосты, цитаты.
  Текст, дата и фильтр approved/rejected меняются, лишь пока ветка не разобрана полностью;
  собранные профильным проходом данные, комментарии и медиа не трогаются.
- Удалённые и скрытые ветки в БД не попадают, в итоге они считаются как «не открылись».
- Запуск пишется в `runs` (`kind = 'search'`, `settings.source = 'postlist'`).

После сбора авторов-новичков можно завести профилями: `uv run scripts/cli.py discover --since 7d --dry-run`.
