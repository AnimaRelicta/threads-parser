**1. Создать таблицы в БД**
```bash
uv run scripts/dbadmin.py migrate      # применяет scripts/db/migrations/*.sql
uv run scripts/dbadmin.py status       # проверить: какие миграции применены, сколько строк в таблицах
```

**2. Записать аккаунт в БД**
```bash
uv run scripts/accounts.py add 1              # новый аккаунт: окно браузера, ручной вход, куки -> БД
# или перенос уже существующих кук/старого реестра:
uv run scripts/accounts.py import threads_cookies.json --user-agent "<UA браузера>"
uv run scripts/dbadmin.py import-accounts     # разово из старого data/accounts.json, если он есть
```

**3. Парсинг постов профиля в Threads**
```bash
uv run scripts/run.py vseobovsem030407 --limit 3 --comments
uv run scripts/run.py --since 1m --comments     # все профили из data/threads_profiles.txt
```

**4. Поиск по Threads (сбор постов по запросу — это и есть «парсинг веток»; дальше их авторов можно брать в список профилей для п.3)**
```bash
uv run scripts/search.py "олх ветка астана" --since 7d
uv run scripts/search.py --file data/threads_queries.txt --since 7d
```

**5. Статистика**
```bash
uv run scripts/accounts.py list        # аккаунты + сводка по запускам
uv run scripts/search.py --stats       # 4 отчёта по поиску: общая картина, качество запросов, темы, очередь задач
```
